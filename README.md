# Аналіз продажів відеоігор

Аналіз консольних ігор (16 598 записів) 
за жанром, регіоном, роком, видавцем і платформою.

## Що досліджувала
- Який жанр продається найкраще в різних регіонах
- Як змінювались продажі за роками
- Які видавці й платформи лідирують за продажами
- Топ-10 найуспішніших ігор усіх часів
- Чи великі жанри лідирують саме завдяки кількості ігор, а не силі кожної гри
- Як почуваються нішеві жанри (Puzzle, Adventure, Strategy) окремо від великих

## Ключові висновки
- Action домінує на Заході, але в Японії відносно сильніший Role-Playing (що також впливає на розвиток аніме тайтлів цієї тематики)
- Продажі падають після 2011–2016, але це через сам датасет: 
  він рахує лише фізичні копії й не бачить цифрового продажу
- Найуспішніша платформа: PS2
- Найуспішніша гра всіх часів у наборі: Wii Sports


## Обмеження
Дані зібрані з vgchartz.com і не враховують цифрові продажі, тому цифри  після 2011 року не відображають реальний стан ринку, а лише продажі 
фізичних копій.

## Інструменти
Python, pandas, matplotlib

## Дані
[Video Game Sales на Kaggle](https://www.kaggle.com/datasets/gregorut/videogamesales)
